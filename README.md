# gist-604b-assignment2
GIST 604B Assignment 2: QGIS Desktop GIS Projects

## Overview
This repository contains QGIS project files and outputs that demonstrates my ability to successfully complete analysis and create maps in QGIS. In the projects folder, there are 10 .gqz files, one for each of the QGIS tutorials I completed. The outputs folder contains screenshots depicting the final map created in each of the tutorials. Through these tutorials I became familiar with the QGIS project space and how to make a map, examine attributes, and change the projection. I also practiced vector and raster analysis, joins, queries, and creating heatmaps. All of these skills are essential for conducting analysis and creating maps for export in QGIS. 

## Software Environment
All QGIS tutorials were completed using QGIS Long Term Release version 3.44.15. I am running QGIS on a Windows operating system and no additional plugins were used.

## Skills Demonstrated
The skills that I developed through these tutorials are:
- Importing and editing spatial data and CSV files
- Editing layer symbology 
- Working with projections and coordinate reference systems (CRS)
- Attribute table editing and joins
- Basic spatial analysis of raster and vector data
- Creating a heatmap using the heatmap renderer as well as the Heatmap (Kernel Density Estimation)

## Reflection
I am new to QGIS, so I learned a lot about how to use the software by completing the tutorials. Through hands-on work the overall setup of the software became much clearer, and I feel overall more confident in using QGIS. For example, I now understand how to add data to a map, change the projection, edit the symbology, examine the attributes and complete common spatial analysis functions. I feel confident in my ability to use all of these skills for GIS projects moving forward. Some things that I found challenging were using the expressions regularly and resolving a few errors that came up. Being new to QGIS, I noticed that there are many cases where it is useful or preferable to use expressions. It was challenging at first to understand the syntax of the expressions, but practicing helped me understand them better. There were a few cases where an unexpected error came up, which required some research and problem solving to resolve. Overall, I have a much better understanding of how to use QGIS. I will continue to use and improve upon these skills for analysis and mapping of my GIS projects going forward.
